# 问题四：40次运行绘图材料

本文件夹可单独复制。运行 `python 绘图.py` 即可从 `40次绘图数据.csv` 重新生成两张图的 PNG、PDF 和 SVG 版本。需要 Python、matplotlib、seaborn；中文字体优先使用微软雅黑、黑体或思源黑体。

`40次绘图数据.csv` 是从40份同心环方案指标JSON提取的最小绘图数据，每行代表一次运行，含清除源数、总虚拟时间、移动距离、检测次数、清除成功与失败次数。表内没有队号、机器人标识、案例编码、个人目录路径或原始接口请求。脚本只读同文件夹中的CSV，并把图输出到同文件夹；没有个人绝对路径。

图1按原题口径计算每次的平均定位清除时间：该次任务总虚拟时间除以该次成功清除源数。图2按速度5 m/s、检测5秒/次、成功清除5秒/次、失败清除3秒/次计算移动、检测和清除耗时；剩余部分标为“换频等剩余耗时”，使每根柱与模拟器虚拟总时间相等。

若换用新数据，保持CSV列名与计时单位一致，并修改脚本中固定的40行校验及图题。
