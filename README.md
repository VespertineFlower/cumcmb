# 支撑材料说明

## 代码

`代码`目录包含问题三（`Q3`）、问题四（`Q4`）和两题共用的官方接口模块（`shared`）。Q3、Q4 各自保留 Baseline 与优化方案：`baseline`、`optimized` 分别存放控制器和运行入口，`common` 存放该题共用的几何、定位、规划及日志功能。`shared/official_client.py` 负责与官方模拟器通信。

问题三的优化方案采用七点覆盖、示向定位与滚动调度，并在已有停靠点执行机会性观测。问题四的优化方案采用 25 点同心环搜索布置，处理全向与定向干扰源的检测、定位和清除。

正式运行代码需要 Windows 和 Python 3，仅使用 Python 标准库。在官方模拟器中登录并启动对应问题的测试，待接口显示就绪后，双击相应脚本，按提示输入当前模拟器登录的参赛队号：

1. 问题三优化方案：`代码\Q3\start_optimized.bat`。
2. 问题四优化方案：`代码\Q4\run_optimized.bat`。

两题应分别在对应测试界面运行；程序生成的本地日志、指标文件和路径图位于各题运行目录的 `logs` 文件夹。

## 绘图部分

`代码\绘图部分`中的 Q3、Q4 文件夹各自包含绘图脚本、输入数据和已生成的图，可单独复制和运行。绘图需要 Python 3、matplotlib、seaborn；Q3 脚本还需要 numpy。绘图脚本按自身所在目录查找输入文件，不依赖原电脑的绝对路径。

- Q3：在 `代码\绘图部分\Q3` 中运行 `python plot_comparison_figures.py`。脚本读取 `logs` 中 Baseline 与优化版各 20 次的指标 JSON 和运行指标 CSV，在 `figures` 中生成时间构成图、单位目标耗时稳健性图。
- Q4：在 `代码\绘图部分\Q4` 中运行 `python 绘图.py`。脚本读取同目录的 `40次绘图数据.csv`，生成同心环方案 40 次运行的平均定位清除时间分布图和逐次时间分解图。

两套脚本均输出 PNG、SVG、PDF 格式，SVG 和 PDF 可用于论文及演示文稿。Q3 两组演练来自不同随机案例，图中不作逐次配对比较。Q4 的逐次时间分解将移动、检测、清除之外的时间归为“换频等剩余耗时”。再次运行绘图脚本会覆盖同名图文件。

## 正式测试日志说明

`正式测试日志文件`下按 `Q3`、`Q4` 分开整理正式测试日志。每题分别用 `1`、`2`、`3` 三个文件夹对应第一次、第二次、第三次测试；日志文件名保持模拟器导出时的原名。
